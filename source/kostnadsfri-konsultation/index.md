Jag erbjuder 20 minuters konsultation med mig alldeles kostnadsfritt. Du får möjlighet att berätta vad som bekymrar dig eller vad du tror att du skulle behöva hjälp med och jag ger dig råd kring hur du kan gå vidare. Om jag tror att jag kan hjälpa dig, säger jag naturligtvis det. Annars ger jag förslag på vart du kan vända dig för att få hjälp.
